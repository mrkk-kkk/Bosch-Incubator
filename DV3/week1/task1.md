Відтворення та запуск:

В мене плата ZyboZ7-10. При створенні проєкту в vivado я замінив констрейн, знайшов гітхаб з файлом. Шукав також в мануалах самої плати, але там лиш був опис MIO 500/501. Проаналізував вміст, як прив'язуються зміні до елементів на платі. Провів симуляцію та завантажив bitstream на плату для перевірки. На платі нема світлодіоду LD5, відповідно лиш один LD6 горить різними кольорами.

Тестбенч:
Перевірка відображення світлодіодів при натисканні btn при кожному варіанті стану switch.

Спочатку при запуску очікується 10 верхнів фронтів клоку. Свічі в цей момент 11. Після починається цикл де молодший біт свіча = молодшому біту i а старший біт свіча =  старшому i. Оскільки цикл i < 4; i++, ми проходимось по кожному можливому стану свіча (00,01,10,11). Далі чекаємо 50 верхніх фронтів клоку, після натискаємо кнопку, кожна наступна кнопка 1, попередня назад в 0.
Дизайн:
Задані стани duty cycle (як довго перебуває сигнал в 1) для світлодіодів (100,60,30). Використання тернарних операторів для визначення яскравості світлодіодів, в залежності від стану свіча та кнопки.
Поведінка:
Завантажив bitstream на плату. При натискані на кнопки зелені світлодіоди змінюють свій стан відповідно assign

```systemverilog
assign LD0 = btn[0];   // натиснута BTN0 вмикає LD0
assign LD1 = sw[0];    // SW0 вмикає LD1
assign LD2 = btn[2];   // натиснута BTN2 вмикає LD2
assign LD3 = !btn[3];  // натиснута BTN3 вимикає LD3
```

Тим часом залежно від кнопок, які натискаєш, LD6 (назва на платі) змінює колір. Це  працює завдяки зміні duty cycle червоного зеленого та синього світлодіода.

Другий свіч не дає ніякого видимого результату, оскільки LD5 відсутній.

Якщо натиснути btn0 при sw0 = 0, світлодіод світиться синім, оскільки спрацьовує ресет і клок перестає подаватися на плату. Оскільки "{led_30_pcent, led_0_pcent, led_100_pcent};", червоний не працює бо "assign led_30_pcent = clk_100_dutycyc_35;" а синій залишається горіти.
